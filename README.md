# 오목

브라우저에서 바로 하는 오목 게임입니다. 서버 없이 HTML/CSS/JavaScript만으로 만들었고,
맥과 휴대폰에서 모두 돌아갑니다.

## 하는 방법

- **둘이서 하기**: 한 기기에서 번갈아 둡니다.
- **컴퓨터와 하기**: 난이도(쉬움/보통/어려움)와 내 돌(흑/백)을 고릅니다.
- **규칙**: 기본은 자유 규칙. 렌주 규칙을 켜면 흑은 3-3, 4-4, 6목 자리에 둘 수 없습니다
  (누르면 빨간 X로 알려 줍니다).
- 마우스는 한 번 클릭하면 바로 놓이고, 휴대폰은 **한 번 누르면 흐린 돌로 미리 보기 →
  같은 자리를 한 번 더 누르면 확정**입니다.
- 왼쪽 위 "오목" 로고를 누르면 언제든 첫 화면으로 돌아갑니다.

## 파일 구성

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 화면 뼈대 |
| `css/style.css` | 모양 |
| `js/rules.js` | 승리 판정, 렌주 금수 판정 |
| `js/ai.js` | 컴퓨터 상대 |
| `js/sound.js` | 돌 놓는 소리 |
| `js/app.js` | 화면과 게임 진행 |

내 컴퓨터에서 해 보려면 `index.html`을 더블클릭해서 브라우저로 열면 됩니다.

## GitHub Pages로 올리기

1. GitHub에서 이 저장소(`omok`)로 들어갑니다.
2. 위쪽 메뉴의 **Settings**(설정)를 누릅니다.
3. 왼쪽 메뉴에서 **Pages**를 누릅니다.
4. **Build and deployment** 아래 **Source**를 **Deploy from a branch**로 둡니다.
5. **Branch**에서 게임 파일이 있는 브랜치(보통 `main`)를 고르고, 폴더는 **/ (root)**로 둔 뒤
   **Save**를 누릅니다.
6. 1~2분 기다린 뒤 같은 Pages 화면을 새로고침하면 위쪽에
   `https://<내 아이디>.github.io/omok/` 주소가 나옵니다. 이 주소를 열면 바로 게임이 됩니다.

> 휴대폰에서는 이 주소를 열고 "홈 화면에 추가"를 하면 앱처럼 쓸 수 있습니다.
